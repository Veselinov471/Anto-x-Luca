# Personas — Anto x Luca (Provisional)

> **All personas are hypotheses.** They must be validated with ad audience performance, landing behavior, and waitlist demographics — not treated as facts.

Working brand: **Anto x Luca**  
Market: Bulgaria  
Wave 1 offer: Early-access waitlist

---

## Persona 1 — “Sofia Professional” (Maya)

| Attribute | Hypothesis |
| --- | --- |
| Age | 28–34 |
| Location | Sofia |
| Lifestyle | Office + café culture; weekends in the city; Instagram as discovery |
| Income / spend | Mid to upper-mid; will spend €80–€150 on a bag if it feels “worth it” |
| Fashion preferences | Clean, modern, minimal logos; prefers quality basics with one statement accessory |
| Online shopping | Regular Fashion Days / brand sites; comfortable paying by card |
| Handbag behavior | Owns 2–4 bags; replaces when style feels dated or leather peels |
| Price sensitivity | Medium — compares to Lemisa/Alore range; rejects “cheap look” |
| Made in Italy | Signal of quality and status at work; not blind loyalty |
| Trust concerns | New brand, returns, whether leather is genuinely Italian-made |
| Purchase triggers | Beautiful photography, everyday versatility, early-access exclusivity |
| Objections | “Why not buy Lemisa?”, unclear company, slow shipping |
| Discovery | Instagram ads, friends’ Stories, fashion influencers |
| What prevents buying | Weak photos, hidden price, no returns clarity, dropshipping vibe |

**Validation:** Meta 25–34 Sofia + craftsmanship/lifestyle creatives → waitlist + product preference mix.

## Persona 2 — “Plovdiv Style-Conscious Mom” (Elena)

| Attribute | Hypothesis |
| --- | --- |
| Age | 35–44 |
| Location | Plovdiv / large regional city |
| Lifestyle | Family + work; practical elegance; less trend-chasing |
| Income / spend | Household budget aware; wants durable leather |
| Fashion preferences | Neutral colors, roomy enough for daily life, timeless |
| Online shopping | Buys online if COD / clear returns available historically |
| Handbag behavior | One “good” bag for years; gift herself after milestones |
| Price sensitivity | Medium-high; needs value narrative |
| Made in Italy | Craftsmanship and longevity story more than fashion prestige |
| Trust concerns | Will it look like photos? Can I return? Who do I call? |
| Purchase triggers | Practical dimensions, soft leather claims (only if true), BG support |
| Objections | Price vs local options; fear of online quality mismatch |
| Discovery | Facebook/Instagram; peer recommendations |
| What prevents buying | No phone contact, vague materials, aggressive luxury hype |

**Validation:** 35–44 ad set; product-detail engagement; FAQ opens; form completion.

## Persona 3 — “Varna Everyday Elegant” (Iva)

| Attribute | Hypothesis |
| --- | --- |
| Age | 40–50 |
| Location | Varna / Black Sea cities |
| Lifestyle | Work + social dinners; seasonal travel |
| Income / spend | Stable; willing to pay for leather that lasts |
| Fashion preferences | Classic silhouettes; black/cognac/taupe |
| Online shopping | Mix of local specialists and occasional marketplace |
| Handbag behavior | Replaces rarely; cares about hardware and construction |
| Price sensitivity | Lower on quality; high on “looks cheap” risk |
| Made in Italy | Heritage / authenticity; skeptical of marketing fluff |
| Trust concerns | Authenticity of origin; company legitimacy |
| Purchase triggers | Detail photography (stitching, interior), honest specs |
| Objections | New brand without track record |
| Discovery | Search + social; sometimes physical stores for comparison |
| What prevents buying | Fake scarcity, unsupported “luxury” claims |

**Validation:** Secondary in Wave 1; watch if craftsmanship creative over-indexes.

## Persona 4 — “Gift Buyer” (Nikolay / partner)

| Attribute | Hypothesis |
| --- | --- |
| Age | 30–45 |
| Location | Urban Bulgaria |
| Lifestyle | Buying gift for partner |
| Income / spend | Budget anchored to “safe nice gift” €80–€130 |
| Fashion preferences | Defers to product beauty and clear packaging story |
| Online shopping | Efficient; needs easy choice of “the one” |
| Handbag behavior | Infrequent; high anxiety about choosing wrong |
| Price sensitivity | Medium; wants a clear hero SKU |
| Made in Italy | Easy gift story (“from Italy”) |
| Trust concerns | Returns if she doesn’t like it |
| Purchase triggers | Curated 3–5 options; clear sizes/colors |
| Objections | Too many choices; unclear gift packaging |
| Discovery | Ads targeting broader interests / lookalikes later |
| What prevents buying | Waitlist-only (cannot complete gift purchase now) |

**Note:** Waitlist offer **weakens** this persona’s path. Revisit if gift season is strategic.
