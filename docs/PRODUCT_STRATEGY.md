# Product Strategy — Anto x Luca MVP

## Goal

Launch the validation landing page with **3–5 hero products**, not a large catalog. Learn which silhouettes attract interest before inventory scale-up.

---

## Selection framework

Score each candidate SKU 1–5 on:

| Criterion | Why it matters |
| --- | --- |
| Visual appeal | Ad + hero performance |
| Differentiation | Vs Lemisa/Alore/Fiora lookalikes |
| Price fit | Inside €79–€129 Wave 1 band |
| Margin potential | Unit economics viability |
| Versatility | Everyday use → broader audience |
| Everyday usefulness | Size/compartments for real life |
| Perceived quality | Leather, hardware, stitching |
| Photography potential | Can we shoot premium assets? |
| Gift potential | Secondary segment |
| Seasonality | Avoid dead-season-only items for first test |
| Segment relevance | Fit to Maya / Elena personas |

**Rule:** Prefer a spread of silhouettes (e.g. crossbody, medium tote, structured shoulder) and 1–2 colorways max per silhouette for clarity.

## MVP merchandising rules

1. Show **price on collection cards** (EUR + BGN).
2. Mark **Made in Italy** only if true for that SKU.
3. No “bestseller” badges without data.
4. Prefer fewer SKUs with excellent photos over more SKUs with weak photos.
5. Track interest per `product_id` in waitlist + analytics.
