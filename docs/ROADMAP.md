# Roadmap — Anto x Luca

## Phase 0 — Market research

- Competitor analysis, personas, pricing hypotheses
- Open questions & assumptions
- **Status:** In progress via `/docs`

## Phase 1 — Landing page MVP

- Next.js BG landing, dual prices, waitlist, consent, analytics
- Deploy to production domain
- **Status:** Implementation follows docs

## Phase 2 — Paid validation

- Meta Wave 1 (€300–€700)
- Experiment logging
- Weekly readout vs decision framework

## Phase 3 — Preorders / initial sales

- Only if green/yellow with clear iterate path
- May introduce deposit or full checkout
- Real inventory / order-on-demand decision
- Payment provider, order emails, shipping SOP

## Phase 4 — Full e-commerce

- Catalog, PDP, cart, checkout, payments
- Order management, returns workflow
- Customer support tooling / light CRM
- Expanded SEO content

## Phase 5 — Growth

- Retention, email flows, lookalikes, creative system
- Possible retail/pop-up tests
- EN locale / cross-border if BG proves out

## Explicit non-goals until Phase 3+

Mobile app, loyalty, marketplace integrations, recommendations engine, heavy CMS, complex OMS.
